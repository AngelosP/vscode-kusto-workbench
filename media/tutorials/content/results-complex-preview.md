# Complex values can show configurable inline previews

Use **Preview complex values** in the results toolbar when you want a quick look inside JSON objects and dynamic arrays without opening each one.

![Configurable inline previews beside complex values](images/tip-results-complex-preview.png)

Set **Max characters** to expand or contract the table's existing complex-column width cap. **View** and the inline cell retain the same complete value; the table's existing ellipsis handles what fits.

Table search highlights matching text directly in an enabled preview.
